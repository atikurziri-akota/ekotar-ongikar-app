একতার অঙ্গীকার — Installable Web App package

GitHub repository-এর root folder-এ এই ZIP-এর ভেতরের ফাইলগুলো আপলোড করুন (index.html, manifest.webmanifest, sw.js, icons/).

গুরুত্বপূর্ণ:
1) index.html হলো বর্তমান সদস্য/অ্যাডমিন অ্যাপের কপি।
2) GitHub Pages HTTPS-এ চালু থাকতে হবে।
3) Android: Chrome-এ অ্যাপের ওয়েব ঠিকানা খুলে Install app / Add to Home screen।
4) iPhone: Safari-তে ওয়েব ঠিকানা খুলে Share > Add to Home Screen।
5) লগইন, জমা, অনুমোদন ও ডেটাবেসের কাজের জন্য ইন্টারনেট লাগবে। Offline cache শুধু অ্যাপের মূল ফাইল দেখাতে সাহায্য করে।
6) ZIP ফাইল সরাসরি WhatsApp-এ পাঠালে এক ক্লিকে ইনস্টল হবে না; GitHub Pages-এ প্রকাশ করে লিংক শেয়ার করতে হবে।
7) Supabase publishable key frontend-এ থাকতে পারে; service_role/secret key কখনো এখানে যোগ করবেন না।
